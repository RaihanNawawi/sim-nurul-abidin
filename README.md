# Sistem Informasi Masjid Jami' Nurul Abidin

Website Masjid Jami' Nurul Abidin yang dikembangkan sebagai pusat informasi digital untuk memperkenalkan masjid, menyampaikan aktivitas dan kebutuhan masjid, serta mempermudah masyarakat mengetahui cara berkontribusi.

## Project Overview

- **Project Type:** Website / Information System
- **Project Stage:** MVP
- **Current Phase:** Blitzkrieg Phase
- **Development Approach:** Rapid Development & Iterative Refinement

## Objectives

- Menyediakan pusat informasi masjid yang mudah diakses.
- Memperkenalkan profil dan aktivitas masjid.
- Menyampaikan informasi kebutuhan masjid.
- Mempermudah masyarakat mengetahui cara berdonasi dan berkontribusi.
- Mendukung publikasi informasi melalui media sosial.

## Core Features

1. **Masjid Profile** — Informasi dan profil masjid.
2. **Activities** — Informasi kegiatan dan dokumentasi aktivitas.
3. **Masjid Needs** — Informasi kebutuhan masjid.
4. **Donation Information** — Informasi cara berdonasi.
5. **Contact & Location** — Informasi kontak dan lokasi.

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5.3.9
- Bootstrap Icons 1.13.1
- Vanilla JavaScript
